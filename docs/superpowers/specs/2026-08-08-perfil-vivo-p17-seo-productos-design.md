# Perfil Vivo — P17 lite SEO/AEO (productos + llms)

**Date:** 2026-08-08  
**Source:** `08` §§2–5

## Goal

Cada producto destacado es una landing indexable; el dominio declara llms.txt; bots de IA no bloqueados.

## Shipped

- `/v/{slug}/producto/{id}` + rewrite `/@{slug}/producto/{id}`
- JSON-LD Product + Offer
- Enlace “Ver página del producto” desde la hoja del catálogo
- `public/llms.txt` + robots AI bots allow
- Track `whatsapp_click` en CTAs del Perfil Vivo
