# SEO off-site — checklist operativo (Fase 5)

Tareas que **no** viven en el repo; responsable del equipo Buscadis.

## Google Search Console

1. Propiedad: `https://www.buscadis.com`
2. Variable en Vercel: `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`
3. Enviar sitemap: `https://www.buscadis.com/sitemap.xml`
4. Tras cada deploy SEO: Inspección de URL → URLs con snippet de error histórico → Solicitar indexación
5. Revisar quincenal: Cobertura, páginas canónicas, Core Web Vitals

## Google Business Profile (Cusco)

1. Descripción completa (empleos, inmuebles, vehículos, clasificados)
2. Web: `https://www.buscadis.com`
3. Fotos reales (equipo, eventos, capturas app)
4. Meta: 15–30 reseñas auténticas en 60 días

## Marca y SERP

1. LinkedIn **empresa** como entidad principal; perfil personal enlaza a `linkedin.com/company/buscadis`
2. Cada post en IG/TikTok/Facebook → enlace canónico `/a/{id}/{slug}`
3. Play Store: un listing destacado desde `/app` y web
4. `jairosaul.com`: enlace “Sitio oficial” a www o `noindex` en página del proyecto si compite con marca

## Backlinks locales (Cusco)

1. Cámaras de comercio, universidades, medios locales
2. Anclar a `/l/cusco/empleos`, `/categoria/empleos`, o avisos destacados

## Métricas

- GA4: sesiones orgánicas → publicación / contacto
- GSC: impresiones no-marca (`empleo cusco`, `clasificados cusco`, etc.)
