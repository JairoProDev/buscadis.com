# @buscadis/ui

Primitives for Buscadis (Sprint 3+). Consumes `@buscadis/tokens`.

```tsx
import { Button, IconButton, Icon, Input } from '@buscadis/ui';

<Button variant="primary">Guardar</Button>
<Button variant="publish">Publicar</Button>
<IconButton aria-label="Notificaciones" variant="ghost">
  <Icon name="bell" />
</IconButton>
```

Stack: Radix + CVA + Lucide. No raw hex in this package.
